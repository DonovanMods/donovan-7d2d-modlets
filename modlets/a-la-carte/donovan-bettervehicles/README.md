# Donovan's Better Vehicles

Updates the vanilla vehicles with more storage and higher forward speeds.

| Vehicle | Storage | Forward speed | Turbo speed |
| --- | ---: | ---: | ---: |
| Bicycle | 20 slots | 6.25 | 10 |
| Minibike | 40 slots | 8.75 | 13 |
| Motorcycle | 80 slots | 12.5 | 19 |
| 4x4 Truck | 90 slots | 11.25 | 17 |
| Gyrocopter | 60 slots | 14 | 21 |

The 4x4 uses v3.0's 90-slot vehicle-storage maximum. Its storage UI is now managed by the base game, so this modlet no longer patches XUi windows.
