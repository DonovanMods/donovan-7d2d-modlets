# Donovan's Sandbox Preset

Adds a **"Donovan"** preset to the Sandbox Options screen when starting a new game.

Game version 3.0 added native Sandbox Options that made several of my modlets unnecessary (LessGrind, MoreBooks, MoreLootbags, MorePerks, and their mega* variants). This preset applies my recommended values for those options in one click, so a new game feels like the old modded experience.

## Recommended Settings

The preset encodes the following (everything else stays at default):

| Sandbox Option | Value | Replaces |
|---|---|---|
| Harvesting Output | 200% | LessGrind |
| Mining Output | 200% | LessGrind |
| Scrapping Output | 150% | LessGrind |
| Crafting Time | 50% | LessGrind |
| Crafting Input | 75% | LessGrind |
| Crafting Magazines Loot Count | High | MoreBooks |
| Loot Bag Chance | High | MoreLootbags |
| Skill Points Per Level | 2 | MorePerks |

Feel free to open the Sandbox Options after selecting the preset and tweak anything to taste — the preset is just a starting point.

## Maintainer Notes (regenerating the preset code)

The `code` attribute in `Config/sandbox_overrides.xml` is generated by the game:

1. Start a New Game and open the **Sandbox Options** window.
2. Set the options from the table above.
3. Click **Copy Code** and paste the result into the `code` attribute.
4. Uncomment the `<append>` block if it is still commented out.
